# 组合声音素材

这里保存本项目现有组合引用的 WAV、MP3 和声音元数据，随源码一并提供。完整运行包也包含相同文件。

`<UUID>.json` 记录中文名称、时长、来源、音频地址及 SHA256；相应 WAV 使用 UUID 加版本标识命名。历史组合可能引用旧版本声音，不能只保留最新同名素材。

这些音频用于重现项目演示；其中音乐等第三方素材的权利归原权利人，公开提供不代表授予额外的商业或再分发权利。自己制作演示时可在编排器中替换音频。
