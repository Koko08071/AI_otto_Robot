# 已保存组合

每个 JSON 文件对应一个组合，文件名为组合 ID；文件内 name 为显示名称，trigger 为语音触发词，tracks 保存轨道与片段。

片段含保存时的资源快照，修改动作库不会自动同步已有组合。建议通过网页编排器修改后保存。
手势引用的组合 ID 配置在 ../../../gesture_recognition/gesture_actions.json。

部分组合引用的本地音频未上传，需补齐音频才能完整播放。
