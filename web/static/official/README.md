# 表情素材

本目录存放 GIF 表情及预览资源；具体名称、时长、ID 和素材路径见 [../expressions.json](../expressions.json)。

- thumbs/：资源卡视频缩略图。
- _drafts/：设计草稿和候选版本。

本目录名为 official，但资源来源需逐项参考目录记录，不能把所有扩展表情都视作上游官方素材。新增网页预览不会自动增加机器人固件表情。
