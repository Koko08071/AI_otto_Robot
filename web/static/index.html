指令格式与四轴顺序

数组顺序：[左腿, 右腿, 左脚, 右脚]。duration / period 单位为毫秒，phase 为角度。

move：pose 为四轴目标角度。oscillate：90 + offset + amplitude × sin(2πt / period + phase)。hold：保持当前状态。output：enabled 开关舵机输出。

角度范围 0–180°；消息容量 65536 字节；累计时长使用固件 32 位毫秒计数。保留库内默认动作，同时允许直接改写幅度、相位、周期与姿态。
